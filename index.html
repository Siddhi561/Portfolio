QUEUE /job-queue public repo

Background job processing service using Redis queues and BullMQ workers, with retries, dead-letter queues, and PostgreSQL persistence for async email delivery.

  • Queues the job and returns 202 immediately.
  • Priority queuing (1-10) and 5-way worker concurrency.
  • Exponential-backoff retries (5s, 25s, 125s) with a dead-letter queue after 3 failures.
  • Writes the job row to PostgreSQL before queuing, so no job is orphaned.

HOOK /webhook-service public repo

Webhook delivery platform with HMAC signature verification, exponential backoff retries, and event persistence for third-party integrations.

  • One job per subscriber per event, so one failing subscriber does not block the others.
  • Payloads signed with HMAC-SHA256; requests older than 5 minutes are rejected.
  • 5-stage exponential backoff per subscriber, with full delivery history stored in MongoDB.
